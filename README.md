# CodeAlpha Chatbot

This is a simple rule-based chatbot built using Python in Jupyter Notebook.
This project was created as part of the CodeAlpha internship.

## About the Project
A basic chatbot that responds to predefined user inputs like greetings, 
questions about itself, and goodbyes. It uses simple if-elif logic to 
match user input with appropriate responses.

## Features
- Responds to greetings (hello, hi, hey)
- Answers basic questions (how are you, what is your name)
- Ends conversation
